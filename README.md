# 💼 AI Career & Portfolio Analyzer

AI Career & Portfolio Analyzer is an intelligent tool designed to help job seekers, students, and professionals analyze their resumes, structure their portfolio, and prepare tailored cover letters using AI.

## 🌟 Features
- **Comprehensive Resume Review:** Analyzes strengths, weaknesses, and missing skills based on targeted job roles.
- **Automated Cover Letter Generation:** Generates professional and tailored cover letters in seconds.
- **LinkedIn Profile Optimization:** Provides actionable tips to make your professional profile stand out to recruiters.

## 🛠️ Tech Stack & APIs Used
- **Frontend/UI:** Streamlit (Python framework)
- **AI Integration:** OpenAI API (GPT Models)
- **Language:** Python 3.10+
